# ACMEPOINT 進金生能源｜維運資產與合約決策平台 (OSS Executive Portal)

線上網址：<https://davidyeh51.github.io/oss-site-portal/>

本專案為 **進金生能源服務股份有限公司（ACMEPOINT Energy Services Co., Ltd.，進能服 · 6692）** 內部專用之維運案場、履約合約、客戶資產與颱風風險戰情平台，採用 **McKinsey 顧問級結構視覺語言 ✕ ACMEPOINT 官方品牌識別**，並串接 **Supabase BaaS + Edge Function + RLS** 建構單一金鑰加密解鎖與 60 天定期變更機制。

---

## 核心功能與安全架構

1. **統一金鑰解鎖（Single-Step Access Key Unlock）**
   - 取消繁複的後台多帳號權限管理與第二階段帳密登入，統一使用單一「系統存取金鑰（Access Key）」直接解鎖進入系統。
   - 金鑰以隨機 Salt + SHA-256 雜湊儲存於 `public.oss_access_keys`（前端無法直接讀取），驗證通過後由後端 `oss-account-admin` 動態簽發資料庫讀取憑證，確保未輸入正確金鑰前，資料庫行級安全（RLS）阻斷一切匿名存取。

2. **60 天定期變更提醒與線上輪替**
   - 頁首與機密通知列即時顯示 **60 天金鑰定期變更倒數**（上次變更日、60 天到期日、剩餘天數）。
   - 當金鑰距離 60 天週期僅剩 7 天內或已逾期時，自動顯示醒目提醒橫幅。
   - 點擊頁首 **「變更金鑰」** 即可驗證目前金鑰並換發新金鑰（支援一鍵自動產生強金鑰），變更後立即重設 60 天倒數計時並使舊憑證失效。

3. **多平台風雨戰情地圖（Google 地圖 ＋ 開放型地圖）**
   - 支援 5 種高可用地圖底圖一鍵切換：
     - **Google 地圖（標準街道圖，預設）**
     - **Google 衛星混合圖（空拍＋路網）**
     - **內政部國土測繪中心（通用版電子地圖 NLSC）**
     - **CartoDB 開放型高清地圖（Voyager）**
     - **OpenStreetMap 開放街圖**
   - 全台案場清楚標明於地圖平台上，提供 **「顯示案場名稱標籤」**、**「展開全部案場點位／群聚模式」**、**「重設全台視角」** 以及直接開啟 **Google 地圖定位導航**。
